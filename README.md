# NeoForge Stubs

![Maven metadata URL](https://img.shields.io/maven-metadata/v?metadataUrl=https%3A%2F%2Fregistry.somethingcatchy.net%2Frepository%2Fmaven-releases%2Fcom%2Fpossible-triangle%2Fneoforge_stub%2Fmaven-metadata.xml&label=latest%20version)

This project is meant to be used in a `:common` module of a multi-loader project.
It's purpose is to make it possible to use the [Registrate](https://github.com/tterrag1098/Registrate) project in the `:common` module too, since that requires some NeoForge-classes to be on the class path.
